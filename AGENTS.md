# Onna Studios AI Agent Rules

## Stack
- Flutter
- Dart
- Riverpod
- GoRouter
- Dio
- Freezed
- Json Serializable

## Architecture
- clean architecture
- feature-first structure
- modular approach
- reusable widgets only

## UI Rules
- follow DESIGN.md strictly
- prioritize whitespace
- use rounded-xl style
- premium wellness aesthetic
- soft shadows only
- avoid cluttered layouts

## Coding Rules
- use stateless widgets whenever possible
- avoid duplicated widgets
- keep business logic outside UI layer
- separate presentation/domain/data layers
- use immutable models
- use proper typing everywhere

## State Management
- use Riverpod providers
- avoid unnecessary global states
- isolate feature providers

## Forbidden
- do not hardcode colors
- do not hardcode spacing values
- do not create giant widgets
- do not fetch API directly inside UI widgets
- do not install unnecessary packages

## Performance
- optimize list rendering
- use const constructors
- lazy load large images
- minimize rebuilds

## Deliverables
- clean folder structure
- reusable component system
- scalable architecture
- responsive mobile layout
