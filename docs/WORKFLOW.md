# Development Workflow

## Phase 1
- setup flutter project
- setup architecture
- setup theme
- setup navigation

## Phase 2
- build reusable components
- implement design system
- implement screens

## Phase 3
- implement state management
- integrate mock data
- setup API layer

## Phase 4
- testing
- optimization
- animations
- deployment

---

## Rules
- build components before screens
- build UI before backend integration
- use mock data first
- maintain reusable architecture
