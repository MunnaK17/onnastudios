# Component Guidelines

## Reusable Components

### Buttons
- primary button
- secondary button
- ghost button

### Cards
- class card
- instructor card
- package card
- booking card

### Inputs
- text input
- search input
- filter chip

### Layout
- section container
- app header
- bottom navigation
- modal sheet

---

## Styling Rules
- use theme extension
- use spacing constants
- use radius constants
- avoid inline styles

## Naming Convention
Example:
- class_card.dart
- package_card.dart
